# Image to Base64 Converter

A lightweight, standalone HTML tool to instantly convert image files into Base64 encoded strings for seamless embedding in web projects.

## Features
*   **Direct Embedding**: Generate strings ready to be used in `src="data:image/..."` attributes.
*   **Instant Preview**: View the uploaded image and the resulting code side-by-side.
*   **One-Click Copy**: Quick-copy the full Data URL or just the Base64 string to your clipboard.
*   **100% Client-Side**: No server uploads; your images are processed locally in the browser for maximum privacy.
*   **Multiple Formats**: Supports PNG, JPG, GIF, WebP, and SVG.

## Built With
*   **HTML5 / CSS3**: Minimalist UI for a focused workflow.
*   **Vanilla JavaScript**: Uses the `FileReader` API for high-speed local conversion.

## How to Use
1.  Open `ImageBase64.html` in any modern web browser.
2.  **Drag and drop** an image or click to select a file.
3.  The tool automatically generates the **Data URL**.
4.  Click **"Copy"** and paste it directly into your HTML or CSS code.
